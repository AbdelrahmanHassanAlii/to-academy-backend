# Academy settings

Module: `src/modules/settings/{model,routes,controller,service,validators,utils}/` plus index.ts. One logical record: fixed immutable string _id=academy in the settings collection. MongoDB's _id uniqueness prevents concurrent duplicates. PATCH performs atomic field upsert and retries duplicate-key initialization races as updates. The application never accepts an arbitrary singleton identifier. GET returns safe defaults without writing a document.

Fields: localized academyName, nullable localized about, nullable logo Media ObjectId, nullable contactPhone/whatsappNumber/contactEmail, nullable localized address/footer, socialLinks {facebook,instagram,linkedin,youtube,tiktok,x}, localized defaultSeo {title,description}, database timestamps. Localized objects require Arabic and optionally English. Limits: academyName200/about10000/address1000/footer1000, SEO title200/description600. Names/about/address/footer are plain text; frontends must escape them. Default name: {ar:أكاديمية TO,en:TO Academy}; nullable fields null, links/SEO empty objects.

GET /api/v1/settings returns the approved public fields only. GET /api/v1/admin/settings returns those same editable public fields with no internal IDs/versions/timestamps. PATCH /api/v1/admin/settings requires an active administrator, trusted Origin and current X-CSRF-Token; unrecognized fields and empty patches fail400. This singleton intentionally contains no provider secrets, credentials, private environment configuration or private administrative fields. Explicit DTO allowlists also filter unknown out-of-band database properties.

Phone and WhatsApp contact numbers use the existing strict libphonenumber-js/max normalization, accepting valid Egyptian national/international numbers and Arabic/Persian digits, stored E.164. WhatsApp is contact information only: no provider API or automated messaging. Email validated and lowercased; null clears contacts. Social links accept absolute HTTP(S) URLs, max2048, without embedded credentials; other schemes/protocol-relative links fail. Supplied nested/localized objects replace the whole field; omitted top-level fields are preserved. Use {} to clear socialLinks/defaultSeo. Logo:null clears logo; any non-null logo requires an existing ready public image with a GridFS file, coordinated transactionally with deletion. See [Media](media.md).
